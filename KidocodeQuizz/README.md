# 🧠 Kidocode Web Quiz

A **fun and interactive** quiz platform inspired by **Google Forms, Kahoot, and Quizizz**, designed to let admins create, manage, and publish quizzes.

---

## 📌 Features
✅ **Admin-Only Quiz Creation** – Unlike other platforms, only admins can create quizzes.  
✅ **Difficulty Levels** – Supports **Beginner, Intermediate, and Advanced** quizzes.  
✅ **Real-Time Quiz Preview** – Admins see a live preview as they build quizzes.  
✅ **Drag-and-Drop** – Reorder questions easily.  
✅ **Interactive UI** – Animations, hover effects, dark mode, and sidebar animations.  
✅ **Firebase Integration** – Uses Firebase for authentication and data storage.

---

## 🚀 Tech Stack
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Flask (Python)  
- **Database**: Firebase Realtime Database  
- **Hosting**: GitHub Pages / Firebase Hosting (optional)

## 📂 Project Structure

 Clone the Repository**
```sh
git clone https://github.com/Nzm15/KQuizz

```

1) Install Dependencies
Make sure you have Python and Flask installed:

```sh
pip install flask
```

2) Set Up Firebase
Create a Firebase project at [Firebase Console](https://console.firebase.google.com/).
Reference creating the the real-time (https://www.youtube.com/watch?v=qKxisFLQRpQ)
Get the api-key.env and serviceAccountKey.json files and place them in the project folder.

3) Run the App

```sh
python app.py
```
